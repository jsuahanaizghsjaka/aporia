## Ограничения

Локальные тесты используют реальные Next.js routes и PostgreSQL с изолированными Auth/AI fixtures. Они не являются проверкой облачного Supabase, Windows или ответов реальной модели.

Точные изменения новых оценок записываются с этапа 21. Ранние записи остаются с пометкой неполной истории; незавершённые сессии не получают выдуманную финальную длительность. Время от начала до завершения включает перерывы.

Источник проекта отражает проверку понимания, а не автоматическую проверку исполняемого проекта. В коде нет исполнения пользовательского кода. Тип quiz поддержан схемой реестра, отдельного экрана новых квизов в этих этапах нет.
