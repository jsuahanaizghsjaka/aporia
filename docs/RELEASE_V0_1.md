## Проверки перед фиксацией

Из папки Aporia, остановив её dev-сервер: `npm run verify`, `npm run test:browser`, затем `npm run doctor -- --live` и отдельный `npm run build`. Реальные credentials не должны попадать в Git. При изменении только документации не повторять весь дорогостоящий прогон без причины. SQL-метрики проверяются отдельным `node --experimental-strip-types --test tests/stages40-43.test.mjs`.

`doctor` проверяет метаданные, а не доставку почты и не баланс AI. `check-personal-ai.mjs --live` делает до двух платных синтетических запросов, не записывает в БД; успешный ответ тоже не заменяет живой пользовательский цикл.

3. Откат приложения выполнять в Vercel на предыдущий проверенный READY deployment. На 1 октября предыдущая версия: `dpl_2LgF81d1LEDogpH8omJDsiQAjrqx`; кандидат 14bd95b8 после своей приёмки может стать новой точкой отката. Перед действием проверить её совместимость с текущей схемой/env.
4. Откат приложения не откатывает базу и не возвращает env в прежнее состояние. Новых миграций в 40–43 нет. Данные восстанавливать только по отдельному плану в изолированной базе.
