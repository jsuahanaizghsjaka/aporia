# Aporia: Windows и одна рабочая папка

Актуальная пошаговая инструкция: [START_HERE_WINDOWS.md](START_HERE_WINDOWS.md).

Рабочая папка пользователя — `C:\Users\Sinon\OneDrive\Рабочий стол\Aporia`. Не переносить проект в C:\Dev, не создавать второй репозиторий и не менять ветку. Рабочая среда ChatGPT не имеет прямого доступа к Windows; изменения нужно применить один раз из архива.

Использовать новый пакет `aporia-windows-ready.zip`. Инструкция автоматически распаковывает его внутри Aporia и запускает обновлённый `scripts/update-windows.ps1`. Установщик сохраняет прежние замещаемые файлы в резервный ZIP внутри этой же папки, оставляет Git и локальные env-файлы на месте, обновляет зависимости и проверяет результат. При ошибке npm успех не выводится. Сообщения на английском совместимы с Windows PowerShell 5.1.

После успешного обновления открыть эту же папку в VS Code и выполнить `npm run dev`. Демонстрация — `http://localhost:3000/preview`; использовать порт из вывода сервера. Настоящие аккаунты — после настройки Supabase/AI и отдельной сборки с ключами.

Если EBUSY повторяется, остановить сервер Aporia, приостановить OneDrive и закрыть программы, удерживающие файлы проекта. Не завершать все процессы Node на компьютере. Установщик указывает найденные процессы, чья командная строка содержит путь проекта.

Последнее указание пользователя: **не выполнять commit и push**. Вызовы установки, проверки и запуска их не выполняют. Vercel CLI в этапе 10 публикует сайт отдельно от Git; это будущее действие после настройки сервисов и QA.
