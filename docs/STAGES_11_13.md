# Этапы 11–13

## 11. Mastery Engine

`src/lib/learning/mastery.ts` строит объясняемый показатель из проверенных ответов: правильности, самостоятельности, количества и разнообразия evidence, а также последней практики. Показатель ограничен 95%; просмотр материалов, feedback и повторное нажатие кнопки не добавляют evidence.

## 12. Roadmap Engine

Миграция `202609140007_roadmaps.sql` добавляет `roadmaps`, `roadmap_items`, RLS и атомарную функцию `commit_roadmap`. Маршрут содержит все восемь навыков ровно по одному и проверяет зависимости. AI создаёт только черновик; запись происходит после явного подтверждения пользователя.

Перед запуском приложения в Supabase SQL Editor последовательно выполни миграции `001–007`, затем `supabase/checks/stages11-13.sql`.

## 13. Dashboard

Dashboard показывает активную цель, подтверждённый progress, confidence, evidence, слабые навыки, текущий проект и Today’s Mission. Миссия продолжает незавершённую сессию, затем повторение, затем текущий навык подтверждённого roadmap.
