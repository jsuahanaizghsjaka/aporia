# Этапы 24–27 исходного плана

Источник нумерации: MVP_AI_Mentor_Plan_September_2026.docx. Изменяется существующая Aporia, новая папка приложения не нужна.

## Что добавлено

24. `/learn`: подбор материалов по теме. AI выбирает только из проверенного каталога по подтверждённой цели, профилю, mastery, времени и отзывам. Максимум одна документация, одно видео, один дополнительный источник. Подборка сохраняется; выбранная ссылка добавляется в «Мою библиотеку» отдельной кнопкой. После открытия доступны «Помогло / Не помогло». Подготовленный режим явно обозначен и не вызывает AI.

25. В том же блоке: авторские главы Think Python, Pro Git, Architecture Patterns with Python, выпуск Talk Python и страница издателя Docker in Action. Есть язык, ограничения, платность и объяснение пользы сейчас. Углублённые книги доступны после базовой практики. Контент книг не копируется. Старый подкаст обозначен как обзор, не актуальная инструкция.

26. `/profile`: семь дневных окон 0 либо 5–120 минут, часовой пояс IANA. 0 — выходной. Расписание сохраняется вместе с профилем и его версией. Новый урок ограничен меньшим из запрошенного времени и окна дня. Уже начатый урок сохраняет план и доступен для продолжения частями. Диагностику тоже можно проходить частями. Без расписания прежнее поведение сохранено. Google Calendar не подключается.

27. `/progress`: один сохраняемый снимок последних семи дней за календарную неделю. В отчёте завершённые сессии, измеренное время ответов (повторные попытки не удваивают его), новые свидетельства, изменения уровня, слабые навыки и сданные задачи проекта. Исторические пробелы не подменяются выдуманными данными. AI предлагает доступный фокус; расчёт статистики выполняет сервер. Обзор по данным работает без AI. Фокус включается отдельным подтверждением на семь дней. Повторения и пререквизиты приоритетны, существующий roadmap не переписывается. Его адаптация — отдельный процесс с подтверждением на `/roadmap`.

## База и безопасность

`supabase/migrations/202609260011_personal_learning.sql` создаёт `learning_resources` и `weekly_reviews`. Это проекции серверного состояния, обновляемые в одной транзакции существующего `commit_learning_state`. Клиенту разрешено только чтение собственных строк; прямые записи и вызов функций синхронизации запрещены. Секреты и реальные пользовательские данные в SQL не включены. Старые состояния получают пустые массивы при чтении, профиль — schedule=null.

Для другой базы сначала проверить наличие 001–010 и отсутствие 011. Затем выполнить весь файл 011, после него `supabase/checks/stages24-27.sql`. Первые четыре счётчика должны быть 0, enabled_projection_triggers — 1. Не запускать миграции повторно «на всякий случай».

В проекте Aporia1 (`jccywkmspooajntrqqcj`) 011 применена 27 сентября 2026 после подтверждения владельца. SQL-проверки дали 0/0/0/0/1.

## Проверка

```powershell
npm run verify
npm run test:personal:browser
npm run test:browser
npm run doctor -- --live
```

Тесты используют локальные Auth/AI fixtures и PostgreSQL/PGlite, не настоящие аккаунты и платную модель. `/preview/learn`, `/preview/profile`, `/preview/progress` используют только локальное хранилище и подготовленный режим. Настоящую модель нельзя считать проверенной по mock-тестам.

Последняя реальная проверка генерации вернула `AI_QUOTA`. После восстановления лимита/оплаты OpenAI можно отдельно выполнить:

```powershell
node --experimental-strip-types scripts/check-personal-ai.mjs --live
```

Это до двух платных запросов на синтетических данных, без записи в Supabase. После их успеха нужно проверить AI-подбор и AI-обзор в своём аккаунте через интерфейс.

Ручной сценарий: после входа настроить дни → сохранить и перезагрузить профиль → выбрать подготовленный или AI-подбор на `/learn` → сохранить ссылку → открыть → оставить отзыв → перезагрузить → проверить библиотеку → на `/progress` создать обзор → убедиться, что фокус ещё не изменился → подтвердить доступную тему. После повторного входа всё должно сохраниться, у второго аккаунта данные отсутствуют.

Ограничения MVP: до 100 подборок и 104 недельных обзоров на аккаунт; лимит даёт явную ошибку без удаления истории. Каталог небольшой, курируемый, без веб-поиска произвольных URL. Время ответов — ограниченный серверный замер, не точный трекер активного времени за компьютером. Публикация и Git push в эту задачу не входят.
