# Входит в MVP v0.1

## P0

- веб-приложение Next.js;
- signup, login, logout и защищённые страницы;
- Lesson 0 — естественное знакомство с AI;
- подтверждаемый профиль и постоянная память;
- одна активная учебная цель;
- диагностика по фиксированному дереву Python backend;
- skill map с mastery и confidence;
- изменяемый roadmap;
- dashboard с одной ясной Today's Mission;
- короткая учебная сессия под доступное время;
- Learn Mode и Help Mode;
- teaching policy: `ASK → HINT_1 → HINT_2 → EXPLAIN → PARTIAL_SOLUTION → FULL_SOLUTION`;
- упражнения и проверка ответов;
- один практический проект с задачами, связанными с навыками;
- mastery evidence из диагностики, упражнений, проекта и review;
- сохранение прогресса;
- loading, error, retry и empty states;
- production deployment и полный ручной QA.

## P1

- простая страница прогресса;
- история учебных сессий;
- один основной и один дополнительный внешний ресурс на тему;
- feedback по материалу и занятию;
- weekly review и корректировка roadmap;
- базовые продуктовые события;
- alpha на 3–5 и beta на 10–20 пользователях.

## Ограничения

- один активный goal;
- только Python backend;
- AI использует утверждённое skill tree и не создаёт дубликаты;
- mastery меняется только при наличии evidence;
- существенные изменения профиля подтверждает пользователь;
- внешние материалы рекомендуются ссылками, но не копируются.
